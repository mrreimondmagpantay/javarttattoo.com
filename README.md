# JAVAR TATTOO website

Static one-page website for JAVAR TATTOO, Tanauan City, Batangas.
Fine-line, black & grey realism, portrait and pointillism tattoos, plus piercing.

- `index.html`: the whole site (responsive for desktop, tablet and phone)
- `images/`: gallery photos
- `videos/`: reels (compressed MP4 + poster frames)

Deploy: import this repo in Vercel as a static site (no build step), then add the domain `javarttattoo.com`.
